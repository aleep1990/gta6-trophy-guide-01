# Leonida Ledger — GTA VI Trophy Guide & Tracker

[![Competition](https://make.fun/badge/gta6-trophy-guide-01.svg)](https://make.fun/bounty/gta6-trophy-guide-01)
[![Rank](https://make.fun/badge/gta6-trophy-guide-01/aleep1990/gta6-trophy-guide-01/rank.svg)](https://make.fun/bounty/gta6-trophy-guide-01)
[![Reward](https://make.fun/badge/gta6-trophy-guide-01/aleep1990/gta6-trophy-guide-01/reward.svg)](https://make.fun/bounty/gta6-trophy-guide-01)

An offline guide and tracker for all 55 PlayStation 5 trophies of **Grand Theft Auto VI** — built for the [make.fun bounty](https://make.fun/bounty/gta6-trophy-guide-01).

- **Tracker:** all 55 official trophies with their names, descriptions and grades; progress saved in the browser, export/import as JSON, filters by grade and kind, search, and a spoiler setting that hides story trophies until earned.
- **Guides:** a full guide for every trophy in our own words, with named sources — Exophase for the official list, PSNProfiles for the PSN progress targets, and our own advice from the official description. The game launched 19 Nov 2026: where a place or step is not pinned down yet, the guide says so instead of inventing one.
- **Roadmap:** six stages to the platinum, with per-stage progress.
- **Missables:** the one flagged missable (Positive Mental Attitude) plus the one-time story moments to save before.
- **Next up:** a planner that suggests your next trophies — story order first, then quick wins.
- **Two themes:** dark sunset and light paper. Notes per trophy, keyboard shortcuts, zero network requests.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Node 22 or later, no dependencies, no build step — `app/` is plain static files.

## Hand in
